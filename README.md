# Comp3111LEx

COMP3111 Lab 1 Java/Maven project using JDK 21.

The assignment files and lab documentation are in [src/main/java/Lab1](src/main/java/Lab1/readme.md).

## Run

Open `pom.xml` in IntelliJ IDEA, configure JDK 21, and run `Lab1.mainApp1`.
The power and factorial results are `2048` and `39916800`.
